# Privacy

Sparkles Wallpapers does not collect, transmit, sell, or share personal data.

The extension stores only the selected wallpaper mode and the most recently
shown wallpaper in Chrome's local extension storage. That data stays on the
device and can be removed by uninstalling the extension or clearing its local
storage.

The extension requests only the `storage` permission. It does not request
access to browsing history, page contents, tabs, location, identity, or remote
services.
