# Chrome Web Store listing

## Product details

**Name:** Sparkles Wallpapers

**Summary:** Turn every new tab into a playful Sparkles.dev wallpaper.

**Detailed description:**

Make every new tab a little more playful.

Sparkles Wallpapers brings four original Sparkles-branded scenes to Chrome.
Pick a favourite or let the extension surprise you with a different wallpaper
on every new tab.

Features:

- Four original 2K Sparkles wallpapers
- Fixed and random wallpaper modes
- A calm clock and date display
- One-click shuffle and wallpaper picker
- Press `R` to shuffle from the new-tab page
- A direct path back to Sparkles.dev

No accounts, analytics, advertisements, or remote content. Your wallpaper
preference stays in Chrome's local extension storage.

## Privacy

**Single purpose:** Replaces Chrome's new-tab page with locally bundled
Sparkles wallpapers and lets users choose or shuffle them.

**`storage` permission justification:** Saves the selected wallpaper mode and
the most recently displayed wallpaper in Chrome's local extension storage.

**Data collection:** No user data is collected, transmitted, sold, or shared.

**Remote code:** The extension does not use remote code. All executable code and
wallpaper assets are bundled with the extension.

**Privacy policy URL:**
https://github.com/sparklesdotdev/browser-extension/blob/master/PRIVACY.md

## Test instructions

1. Install the extension and open a new tab.
2. Confirm a Sparkles wallpaper, clock, and date are shown.
3. Select **Choose** and switch between the four wallpapers.
4. Enable random mode, open another new tab, and confirm a wallpaper is shown.
5. Select **Shuffle** or press `R` to change the wallpaper.
6. Open the toolbar popup and confirm its wallpaper picker works.
7. Select the Sparkles logo or **Build something brilliant** and confirm
   https://sparkles.dev opens.

No account or test credentials are required.
